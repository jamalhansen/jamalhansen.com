Everything here is written for developers who know one thing well and are learning the next one. Pick the line that sounds like you.

## "I write Python. I've been avoiding SQL."

Read the [SQL for Python Developers](/series/sql-for-python-developers/) series in order. It uses DuckDB, so there's nothing to install beyond `pip install duckdb`, and every example runs on data you generate yourself.

1. [I know Python; why learn SQL?](/blog/i-know-python-why-learn-sql/)
2. [Run your first SQL query in under 5 minutes](/blog/run-your-first-sql-query-in-under-5-minutes/)
3. [SQL thinks in sets, not loops](/blog/sql-thinks-in-sets-not-loops/), the post that makes the rest click

The series page tracks which posts you've read.

## "I want AI that runs on my own machine."

- [Run AI locally with Python: uv + Ollama](/blog/local-ai-stack-uv-ollama/) is the setup. Twenty minutes, no API key.
- [The Queue Is Full: what I'm building next with local-first AI](/blog/the-queue-is-full/) is where it leads.

## "Tell me what actually happens when AI writes the code."

[I Vibe Coded and Lived to Tell](/series/i-vibe-coded-and-lived-to-tell/) is the honest version: real tools, small models, what broke. Start with [the promo generator](/blog/i-vibe-coded-a-local-ai-powered-promo-generator/) and then read [The Makefile Was Lying to Me](/blog/the-makefile-was-lying-to-me/).

## "I take a lot of notes and get little out of them."

- [Karpathy's LLM knowledge base method](/blog/road-to-agentic-notes/): why it works and how to start.
- [Your notes need metadata](/blog/your-notes-need-metadata/): the small habit that makes notes queryable.

## "I'm studying for an AWS exam."

The [AWS Data Engineer Associate](/series/aws-data-engineer-associate-certification/) series is the unfiltered account: a fail, a pass, and what changed in between.
